## Lab Overview

### Arrays

The array exercises cover one-dimensional and two-dimensional arrays, input/output, traversal, element updates, and basic calculations such as finding extreme values. These programs build the foundation for working with sequential data.

### Searching and Sorting

This section explores ways to find a target element and reorder a collection. The goal is to understand the logic, number of comparisons, and practical differences between introductory searching and sorting methods.

### Stacks

A stack works on the **LIFO (Last In, First Out)** principle. The implementations include operations such as `push`, `pop`, `peek`, display, and empty-stack checks. Typical applications include recursion, expression evaluation, backtracking, and undo actions.

### Queues

A queue follows **FIFO (First In, First Out)** ordering. The lab work includes insertion, deletion, front/rear access, traversal, and empty-queue handling. Queues are useful for scheduling, buffering, service systems, and breadth-first traversal.

### Linked Lists

Linked-list programs introduce dynamically connected nodes. The exercises focus on creating lists, traversal, insertion, deletion, searching, and displaying elements. Variations such as singly, doubly, and circular linked lists may be added as the course progresses.
